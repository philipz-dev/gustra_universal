Compileer voor iPhone (testflight)

Gebruik

npm run deploy:ios

Wat het doet

  1. ios.buildNumber in app.config.ts +1
  2. EAS_SKIP_AUTO_FINGERPRINT=1 npx eas-cli build production + auto-submit (TestFlight)
  3. Bij succes: commit van de buildNumber-bump
  4. Bij falen: buildNumber terugzetten (geen commit)

Compileer voor Android (Play Internal testing)

Gebruik

npm run deploy:android

Wat het doet

  1. android.versionCode in app.config.ts +1
  2. EAS_SKIP_AUTO_FINGERPRINT=1 npx eas-cli build production AAB + auto-submit naar Play track internal
  3. Bij succes: commit van de versionCode-bump
  4. Bij falen: versionCode terugzetten (geen commit)

Eerste keer: Google Service Account JSON koppelen in EAS (Play Console → Users and permissions).

Webversie (gustra.net/webversion)

Gebruik

npm run deploy:web

Wat het doet

  1. npx expo export --platform web (static, baseUrl: /webversion)
  2. Upload dist/ via FTP naar public_html/webversion
