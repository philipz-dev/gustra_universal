Upload for testers (TestFlight / Play Internal)

Only for testers — not an App Store or Play Store public release.

  • iOS → TestFlight
  • Android → Play Internal testing track

How to run

npm run deploy  (or deploy:ios / deploy:android)

What the script asks

  1. Platform: 1 iOS / 2 Android / 3 both
  2. Paste “what to test” notes (end with an empty line) — saved in the git commit; paste into TestFlight manually if you want
  3. Shows a summary of what upload would do
  4. Upload? 1 = Yes, 2 = No — ask twice (double confirm)

After both Yes: bump → EAS → TestFlight / Play Internal → git commit. Failure reverts the bump.

Optional: npm run deploy -- --go jumps to the double Yes/No.

This never submits a public App Store / Play production release.

Web version (gustra.net/webversion)

How to run

npm run deploy:web

What it does

  1. npx expo export --platform web (static, baseUrl: /webversion)
  2. Upload dist/ via FTP to public_html/webversion
